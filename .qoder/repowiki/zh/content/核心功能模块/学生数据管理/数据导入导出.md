## 详细组件分析

### 后端导出接口与实现
- 路由与参数
  - GET /api/data/export
  - 参数：format(csv/json/excel)、fields(逗号分隔字段名)
- 处理逻辑
  - 读取全部数据
  - 根据 format 输出 CSV/JSON
  - Excel 导出提示需要 openpyxl 依赖
- 错误处理
  - 无数据、格式不支持、内部异常均返回统一结构

```mermaid
flowchart TD
Start(["进入导出接口"]) --> GetItems["查询全部数据(get_all)"]
GetItems --> HasData{"是否有数据?"}
HasData --> |否| NoData["返回无数据错误"]
HasData --> |是| BuildOutput["按format构建输出"]
BuildOutput --> CSV{"format==csv?"}
CSV --> |是| WriteCSV["写入CSV并设置UTF-8-BOM头部"]
CSV --> |否| JSON{"format==json?"}
JSON --> |是| WriteJSON["序列化JSON并设置UTF-8头部"]
JSON --> |否| Excel{"format==excel?"}
Excel --> |是| NeedLib["提示需要安装openpyxl"]
Excel --> |否| InvalidFmt["返回不支持格式错误"]
WriteCSV --> Done(["结束"])
WriteJSON --> Done
NeedLib --> Done
InvalidFmt --> Done
NoData --> Done
```

## 性能考虑
- 导出性能
  - 流式输出：使用 StringIO/BytesIO，避免一次性加载大文件到内存
  - 字符集：CSV 使用 UTF-8 BOM，JSON 使用 UTF-8，确保跨平台兼容
  - 分页与筛选：前端分页、后端分页查询，减少一次性传输
- 写入性能
  - 批量插入：逐条捕获异常，保证整体提交
  - 索引优化：对高频查询字段建立索引
- 资源监控
  - CPU/内存/磁盘使用情况可通过系统接口获取

## 故障排查指南
- 导出失败
  - 检查 format 参数是否为 csv/json/excel
  - 确认数据库中有数据
  - 查看后端日志与异常返回
- Excel 导出报错
  - 安装 openpyxl 依赖后重启服务
- 编码问题
  - CSV 使用 UTF-8 BOM 头部，确保 Excel 正常打开
  - JSON 使用 UTF-8 编码
- 批量写入异常
  - 单条数据异常不会影响其他数据的写入
  - 检查字段类型与长度约束
